# Basic Maths

Basic Maths covers fundamental mathematical concepts used in problem-solving and DSA, including number properties, divisors, prime numbers, GCD, and prime factorisation.

## Problems
- [ ] 1. Check if a Number is Armstrong
- [ ] 2. Print All Divisors of a Number
- [ ] 3. Check if a Number is Prime
- [ ] 4. GCD / HCF of 2 Numbers
- [ ] 5. Prime Factorisation of a Number
- [ ] 6. Count Primes in Range L to R

## Concepts Covered
- Number Properties
- Armstrong Numbers
- Divisors of a Number
- Prime Numbers
- GCD / HCF
- Prime Factorisation
- Counting Primes in a Range
