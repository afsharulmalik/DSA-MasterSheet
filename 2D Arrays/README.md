# 2D Arrays – DSA Practice

A **2D Array (Two-Dimensional Array)** is a data structure that stores elements in rows and columns, forming a matrix-like structure. Each element is accessed using two indices: a row index and a column index.

In Java, 2D arrays are useful for solving matrix problems involving traversal, searching, calculations, and transformations.
